## ADDED Requirements

### Requirement: Technical Documentation Scaffold
The project SHALL have a `docs/` structure initialized with placeholder markdown files for Core Architecture, API & Integration, and Extensibility.

#### Scenario: Documentation verification
- **WHEN** a developer looks into the `docs/` folder
- **THEN** they find dedicated placeholders for Architecture, API, and Extensibility guidelines.

### Requirement: Root README Updates
The project's root `README.md` and `README.es.md` SHALL be updated to reference the new `api-gateway` package and the `docs/` documentation structure.

#### Scenario: Discoverability
- **WHEN** a developer reads the root README files
- **THEN** they find clear references to the new BFF package and the location of the technical documentation.
