## Requirements
### Requirement: Contextual Account Injection
The ingestion pipeline SHALL require explicit context about the origin account to guarantee data integrity and cross-exchange idempotency.

#### Scenario: User uploads a CSV file
- **WHEN** the user uploads a CSV file in the wizard
- **THEN** the UI blocks progression until the user explicitly selects a target `Account` (e.g. 'Binance', 'Ledger')
- **AND** the `useImportProcessor` injects this `account_id` into every parsed row before generating the `id_hash`

### Requirement: TransactionMappedData Consumption
The ingestion pipeline SHALL accept the standardized `TransactionMappedData` payload generated by CSV parsing utilities.

#### Scenario: Receiving parsed CSV row
- **WHEN** the `ICsvIngestionPort` returns a valid transaction map with `asset_in` and `asset_out`
- **THEN** the adapter maps it securely to a `CreateTransactionCommand` matching the SQLite `transactions` table schema

#### Scenario: Duplicate ID detection
- **WHEN** a transaction with an existing `id_hash` is ingested
- **THEN** the ledger ignores the duplicate row to ensure idempotency
