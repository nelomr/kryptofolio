## MODIFIED Requirements

### Requirement: Metrics Tab Content Arrangement
The portfolio view SHALL include a specific `TabsContent value="metrics"` tab area that renders the new crypto performance history chart alongside any existing charts AND the new volatility heatmap.

#### Scenario: Navigating to the metrics tab
- **WHEN** the user selects the "Metrics" tab in the portfolio view
- **THEN** the system displays the performance history chart area and the volatility heatmap, effectively arranging the charts cleanly within this dedicated layout space.
